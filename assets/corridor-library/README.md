## Blender 约束

- 资产尺寸按当前网页走廊比例统一，墙高 8.8、走廊宽 16、地面年份轴在中线。
- 先做低面数、哑光、可快速复制的模块；确认视觉后再加细节。
- 相框、展签、灯具和年份节点都使用可替换材质槽，方便后续接入上传照片和生成结果。
