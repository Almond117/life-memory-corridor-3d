# 人生长廊记忆工坊第一版设计规格

## 目标

在现有第一视角“人生长廊”页面旁增加一个独立的“记忆工坊”模式，让用户可以围绕时间轴节点完成上传、主体/背景检查、卡通化检查、3D 结果检查和 Blender 组合入口。第一版只做可点击 UI 和本地模拟状态，不调用生图或 Rodin API。

## 产品模式

- **漫游模式**：保留现有 Three.js 第一视角长廊，用于最终浏览。
- **工坊模式**：全屏编辑工作台，不覆盖漫游中的 HUD 和相机交互。
- 顶部提供“工坊 / 漫游”切换。

## 工坊布局

- 顶部：5 步阶段条：上传、分离、卡通化、3D 化、组合。
- 左侧时间轴：显示年份、标题、缩略图、节点状态和新增节点按钮。
- 中央预览：根据当前阶段展示原图、主体、背景、卡通结果、主体 3D、背景 3D、组合预览标签。
- 右侧检查面板：当前阶段说明、Prompt、风格选项、确认、重试和下一步操作。
- 底部状态栏：当前节点元信息、模拟队列状态、未保存提示和返回漫游按钮。

## 状态与交互

节点状态为 `draft`、`separating`、`split_review`、`stylizing`、`cartoon_review`、`modeling`、`model_review`、`placed`、`error`。第一版用本地计时模拟任务，确认后才进入下一阶段，重试保留旧版本提示。

上传支持点击和拖拽，浏览器只创建本地 Object URL；不上传任何文件到外部服务。默认节点保留示例内容，用户上传后只替换当前节点的原图预览。

## Blender 入口

组合页展示主体/背景模型卡片、2.5D 备选、位置/缩放/旋转控件和“导出 Blender 组合包”按钮。第一版只生成模拟成功提示，不调用 Blender；后续将由服务端生成 `.blend`、`scene.glb` 与 `manifest.json`。

## 时间轴融合

时间轴节点是唯一数据源。工坊左侧时间轴与漫游底部时间轴使用同一组节点；节点完成后，漫游中对应展示位显示 3D 组合，未完成时显示照片占位。

## 非目标

- 本轮不调用 GPT、生图 API、Rodin API 或 Blender。
- 本轮不实现真实账号、云端存储和多人协作。
- 本轮不改变现有长廊的第一视角交互逻辑。
