# 照片到 GLB 交互预览设计

## 目标

在长廊中点击已贴照片后，打开对应的全屏 3D 预览层。预览层加载与照片同名的 GLB 文件，支持拖动环顾、滚轮缩放和 Esc 返回长廊。照片和 GLB 都作为公开仓库中的静态资源管理。

## 资源约定

- 照片：`assets/memories/memory-01.jpg` 至 `memory-04.jpg`
- 模型：`assets/models/memories/memory-01.glb` 至 `memory-04.glb`
- 每个画框的 `memoryId` 同时决定照片路径、GLB 路径、标题和年份。
- 当前仓库没有四个专属 GLB 时，预览层显示清晰的“模型待加入”状态，不阻塞长廊漫游。

## 交互

1. 进入长廊后，鼠标中心准星对准照片并点击。
2. 若该照片有对应 GLB，打开 3D 预览层并载入模型。
3. 预览层使用独立相机和 `OrbitControls`，拖动环顾、滚轮缩放，Esc 或关闭按钮返回长廊。
4. 若模型文件不存在，预览层保留照片、标题和模型路径提示，并提供关闭按钮。
5. 原有 E 键查看记忆详情继续保留，点击照片只新增 3D 预览入口。

## 实现边界

- 继续使用现有 Three.js import map 和 `GLTFLoader`，不新增运行时依赖。
- 预览层使用现有 canvas 之外的轻量 Three.js 场景，关闭时释放模型和纹理资源。
- 不上传照片，不连接外部 API，不加入登录系统。
- README 说明本地启动方式、公开仓库结构、照片与 GLB 命名规则。

## 验收标准

- 公开仓库可以通过静态服务器启动。
- 四张照片仍显示在原有画框中。
- 点击照片能打开对应的 GLB 预览状态；有模型时可漫游，无模型时有明确提示。
- Esc/关闭按钮能回到长廊，原有漫游和 E 键详情不受影响。
